# 🛒 E-Commerce Backend

This is **Version 1** of a scalable e-commerce backend built with Django.

It provides the core business logic and data models required to run an online store.

## 🚀 Features
- Product & category management
- Order & cart system
- User accounts
- Image uploads
- Admin dashboard
- Relational database design

## 🧰 Tech Stack
- Python
- Django
- SQLite (development)

## 📌 Current Stage
This is the **first backend version (v1)**.  
The project will evolve into a full production-ready system.

## 🛣 Roadmap
- Convert backend to REST API using Django REST Framework
- Add JWT authentication
- Build React frontend
- Integrate payments

## 📂 Purpose
This project is part of a professional backend portfolio and is being developed incrementally like a real SaaS product.
